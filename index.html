Step 1 · API keys & models & company list
Signal Researcher — model & API key chain
⚠ Important: models marked ⚠ "reasoning model" in the preset dropdown (GPT-OSS, DeepSeek, and similar "thinking" models) spend part of their output budget on invisible internal reasoning before writing the actual answer — under load, that hidden reasoning can occasionally eat the ENTIRE budget and return a completely empty response. This is why the exact same setup can work for one company and fail on the next — it's not a fixed bug, it's model-dependent and load-dependent. Models marked ✓ are plain instruct models with no hidden reasoning step, so every token goes straight to the visible answer — put one of those as your Primary row for the most reliable results, and keep a reasoning model only as an optional fallback further down the list if at all. Note: Groq retired its whole non-reasoning lineup (llama-3.1-8b-instant, llama-3.3-70b-versatile, gemma2-9b-it, qwen3-32b) in August 2026 — every model Groq still offers is now a reasoning model, so for a genuinely non-reasoning Primary, pick a ✓ preset from another provider (OpenRouter, Cerebras, Gemini, Mistral, or local Ollama).
Add more than one key/model as a safety net — if the first one hits an expired key, a retired model, or a daily quota limit, the engine automatically switches to the next one in the list and keeps going instead of stopping the run. Use the "+ free preset" dropdown on each row for common free options, or type any model ID directly. Get keys: Groq · OpenRouter · Gemini · Mistral · Cerebras · OpenAI (paid, not free). Ollama runs locally and needs no key — just install it, run ollama pull llama3.1 (or any model), and select "Ollama" as the provider (endpoint defaults to http://localhost:11434, editable per-row). Free-tier lineups change over time on all of these — if a preset 404s/401s as "model not found," check that provider's current docs and type in a working model ID.
